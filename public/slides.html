Alexa+ add-on

  • Self-hosted MCP server, spec 2025-11-25, Streamable HTTP
  • OAuth 2.1 + PKCE account linking, protected resource metadata
  • 4 MCP Apps: timeline, checkout, pharmacist, digest
  • Agent Skill: skills/refill-caregiver

Strands Agents SDK

  • TypeScript Agent with McpClient over Streamable HTTP
  • OpenAIModel (Qwen3.8-27B)
  • Hooks stream every MCP call and verdict to the display
  • Steering when a required tool is skipped

Guardrails in code

  • Purchases need caregiver confirmation
  • Rx: explicit OK, quantity locked
  • Monthly budget cap, duplicate prevention
  • Medication questions → pharmacist only
